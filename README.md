# 8 to 5: The Inner Workings of the Marching Band

A responsive, user-friendly website designed to explore the components of a **marching band halftime show** and the **sections** that make up the band.

## 🎺 About the Project

This project serves as an educational guide for understanding what happens behind the scenes of a marching band performance. 

### Key Features
- **Halftime Show Breakdown:** Explains how drill, music, choreography, and themes come together to create a performance.
- **Section Profiles:** Detailed overviews of the Drum Major, Woodwinds, Brass, Percussion (Battery & Front Ensemble), and Color Guard.
- **Interactive Elements:** Features custom photo galleries and an animated performance timeline.
- **Summer Band Camp Quiz:** A built-in interactive quiz to test if you're ready for the field.
- **Support Me!:** Features an integrated fundraising page highlighting cookie and cheesecake sales for band trips and food.

## 🛠️ Built With

- **HTML5:** Structuring the website content, section pages, and forms.
- **CSS3:** Custom styling, responsive layouts (Flexbox/Grid), and visual themes.
- **JavaScript:** Powers the interactive quiz logic, score calculation, and dynamic site navigation.

## 🚀 Getting Started

To view and run this project locally on your machine, follow these steps:

### Prerequisites
You only need a modern web browser (like Google Chrome, Safari, or Firefox) installed on your computer.

### Installation & Running
1. **Clone the repository:**
   ```bash
   git clone https://github.com/yaaAfrehb/Marching-Band.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd Marching-Band
   ```
3. **Open the site:**
   Double-click the `index.html` file, or right-click it and select **Open with [Your Browser]**.
