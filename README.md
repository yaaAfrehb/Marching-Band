## How to Install?

To view and run this project locally on your machine, follow these steps:

### Option 1: Git and Terminal:
1. Install Git on your laptop
 Create a folder or use another for this step and run this command in the terminal:
```bash
cd\Folder\Folder
```
Ex. cd\Pictures\Marching Band

2. Run this command after:
   ```bash
   git clone https://github.com/yaaAfrehb/Marching-Band.git
   ```
### Option 2:
If you don't want to download Git: (I get that)
1. Click on the green **Code** button at the top of this repository page.
2. Click **Download ZIP**
3. Extract *or unzip* the downloaded folder onto your laptop.

Once you have successfully completed one of the two, the files should be on your laptop. It you want to edit and/or run the code by yourself, you can open it on a code editor like VS Code. You could also just open this by clicking on **index.html** and pressing enter or double-clicking it.
